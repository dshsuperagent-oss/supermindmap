# SuperMindMap — mapa mental offline (PWA)

Editor de mapa mental que roda 100% no navegador: escreva em Markdown e o mapa se desenha.
Exporta MD, JSON, SVG, PNG e PDF. Funciona offline depois da primeira visita (service worker)
e pode ser instalado na tela de início do iPad/iPhone.

**Abrir:** https://dshsuperagent-oss.github.io/supermindmap/
